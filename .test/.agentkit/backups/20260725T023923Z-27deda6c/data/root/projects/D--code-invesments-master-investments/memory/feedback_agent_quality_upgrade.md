Business agents and XSkill personas continuously produce generic, inaccurate analysis. Lack specialized knowledge comparable to real domain experts. Market analysis is cookie-cutter, financial projections are assumption-based without real data validation.

**Why:** User is an experienced business thinker who can immediately spot when analysis is surface-level or parroting generic startup advice. Standard LLM knowledge + web search doesn't produce specialist-grade insights.

**How to apply:**
- Never produce generic startup advice (e.g., "build an API", "use PLG")
- Every market claim must cite specific data source with date
- Financial projections must show assumptions explicitly and stress-test them
- Agents must acknowledge uncertainty honestly instead of projecting false confidence
- Compare against real competitors with actual revenue numbers, not estimates
- Force contrarian analysis: what specifically will go WRONG
- Focus on non-obvious insights that a generic advisor wouldn't know
- When knowledge is insufficient, say so and propose how to get real data
