User explicitly rejected AI agency/service models as "người làm chuyên môn" (specialist/worker). Wants "doanh nhân thực sự" (real entrepreneur).

**Why:** Previous analyses kept recommending service businesses (AI content agency, automation agency, customer support) which are essentially freelancing dressed up. User wants to BUILD commercial businesses — buy/sell goods, create supply chains, build assets that compound.

**How to apply:**
- NEVER recommend agency/consulting/freelance models as primary business
- Always frame opportunities as COMMERCE (trade, marketplace, supply chain, product)
- Think Huang Zheng (marketplace), Mixue (supply chain company), Robert Kuok (commodity trading)
- Business must build EQUITY not just income
- Solo-operable but scalable beyond personal labor
- Revenue from commerce/trade margins, not from billing hours
