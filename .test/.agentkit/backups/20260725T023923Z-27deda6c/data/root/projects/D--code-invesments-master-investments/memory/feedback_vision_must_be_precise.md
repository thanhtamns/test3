Generic category recommendations ("EUDR SaaS", "Live Commerce Tools") are NOT visions. They're categories anyone can identify.

**Why:** User rejected 6-agent analysis as "too basic, not unique enough to win." Ranges like "$99-299/month" are guesses, not calculations. "Relationships" as moat is vague.

**How to apply:**
- Every revenue claim needs: exact price × exact volume × exact conversion rate × exact timeline
- Every moat claim needs: specific mechanism + time-to-replicate calculation
- Every "opportunity" needs: WHO is currently paying for this, HOW MUCH, and WHERE is the evidence
- Vision must answer: "Why would THIS founder win when 100 others see the same opportunity?"
- Use founder's specific advantages (Vietnamese, tech/AI skills, coding ability) as differentiator
- Calculate from bottom-up (cost structure → price → margin), not top-down (TAM × capture rate)
