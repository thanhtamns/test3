6+ iterations of "output is generic" complaints (260206→260321). Each fix added prompt instructions. Each fix failed.

**Root cause:** AI agents (regardless of count or prompt length) cannot generate ALPHA — insights unavailable through public search. 90+ agents processing WebSearch results = 90x processing of the same commodity information.

**Why:** LLMs recombine training data. WebSearch returns public info. Adding agents/sections/scoring = more words, same depth. V11→V16 evolution added 0 new CAPABILITY, only new INSTRUCTIONS.

**How to apply:**
- NEVER promise AI can "find non-obvious opportunities" — it can't
- Primary research gate: Require ≥5 real conversations before any /startup analysis
- AI role = AMPLIFIER (validate, calculate, scale, automate) not DISCOVERER
- If user asks "find me an opportunity" → redirect to: "Tell me what pain you've OBSERVED, I'll help you validate and execute"
- Reduce system complexity: 5 deep agents > 90 shallow agents
- 1 specific insight from real-world observation > 48 sections of formatted generic advice
- Questions that create alpha are unanswerable by WebSearch — they require human observation
