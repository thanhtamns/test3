System must FIND better evidence autonomously — not just require proof as a gate, but improve the ENGINE that discovers and extracts proof.

**Why:** Requiring proof without improving search/extraction = system says "insufficient evidence" for everything. The real fix is making the system BETTER at finding evidence, extracting insights from conversations, and recognizing opportunities sharply.

**How to apply:**
- Continuously improve search strategies: deeper queries, more specific patterns, cross-source triangulation
- Extract evidence FROM conversations (forums, discussions, debates) — not just surface-level WebSearch
- Recognize opportunities from MICRO-SIGNALS (price changes, policy shifts, competitor exits, complaint patterns) not macro-trends
- When evidence is weak: GO FIND MORE instead of giving up or guessing
- Multi-angle verification: same claim from 3+ independent sources = strong evidence
- Apply to ALL business analysis: /startup, /stage0, /invest, brainstorm, any advisory output
- System should get SMARTER at finding proof over time via learning loop
