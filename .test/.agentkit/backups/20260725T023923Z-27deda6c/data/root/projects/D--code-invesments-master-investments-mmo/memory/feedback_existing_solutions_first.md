Always search for pre-existing solutions before building anything new. For every requirement:
- **Business problems**: Search for systems designed by other entrepreneurs that solve the same problem
- **Technical needs**: Search GitHub repositories to find similar/related solutions to learn from and build upon
- **Skills/hooks**: Check awesome-claude-code, skills marketplaces, and MCP servers before creating new ones
- Share and analyze found solutions to shorten development process

**Why:** User strongly values leveraging existing work to avoid reinventing the wheel. Development is faster and more robust when building on proven patterns.

**How to apply:** Before any implementation, spend research time on GitHub, awesome lists, and marketplaces. Reference found solutions in plans. Fork/adapt when possible. Only build custom when nothing suitable exists.
