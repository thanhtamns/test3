All 4 brainstormer agents in 260319 session produced generic analysis despite prior feedback (feedback_agent_quality_upgrade.md). Specific failures:

1. Base rates from generic internet articles, not first-principles math
2. "White-label AI SaaS" recommendation = same advice any ChatGPT gives
3. No contrarian insights or non-obvious opportunities
4. No real market data (didn't scrape actual pricing, competitor revenue, agency communities)
5. Unit economics tables look precise but numbers are internet-sourced, not validated
6. Long ≠ deep. 3000-word reports with shallow analysis wrapped in structure

**Why:** Agents follow analysis TEMPLATES, not analysis THINKING. They list frameworks instead of reasoning from mechanisms.

**How to apply:**
- Before ANY business analysis, agents must do REAL research: scrape actual prices, read actual forums (Reddit, Indie Hackers, HN), find actual revenue numbers
- Acknowledge what we DON'T know explicitly instead of presenting guesses as data
- Find the contrarian angle: what do most advisors say, and why might they be wrong?
- First-principles: model the actual mechanism (how does money flow? what creates the value? where is the friction?) instead of category scoring
- Test: would a founder who's actually done $1M/month find this useful? If not, it's too basic.
