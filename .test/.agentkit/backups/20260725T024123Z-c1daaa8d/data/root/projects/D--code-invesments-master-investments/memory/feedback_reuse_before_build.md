Always search for pre-existing solutions before building from scratch.

**Why:** Development time is the most expensive resource. Other entrepreneurs and developers have likely solved similar problems. Reinventing the wheel wastes time and produces inferior results compared to battle-tested solutions.

**How to apply:**
- For business requirements: search for existing business systems/frameworks designed by other entrepreneurs first
- For technical requirements: search GitHub repos for similar/related solutions to learn from and build upon
- For skills/agents: constantly explore the market for excellent pre-built skills, then auto-update the system
- Share and analyze found solutions to shorten development process
- Only build custom when no adequate solution exists or integration cost exceeds build cost
- This applies to ALL work: code, business strategy, agent skills, workflows
